Foundation First Observation Tracker

Quick Start Tutorial · For authorized staff

← Back to tracker
Purpose: Track weekly observer assignments and the payment process in one shared system, without entering the same classroom twice.
Workflow: Scheduled → Submitted → Processing → Completed.
1

Open the tracker and select the season

Open the tracker website (no sign-in needed). The first time on a new computer, use ⬆ Restore to load the latest backup file. Select the correct Fall or Spring window. Fall runs August 17–December 23; Spring runs January 19–May 29, regardless of weekends or holidays.

2

Upload the weekly schedule

Choose Upload weekly schedule and select that week's CSV. This lists the expected observers, dates, programs and classrooms; it does not mean they have been submitted for payment. Use Weekly schedule to review who is assigned to each classroom.

3

Upload submitted observations

When the payment submission CSV is ready, use Upload submitted CSV (Contractor) or (Internal). Matching observations move to Submitted. Review the Upload Review Center for unmatched rows or classroom/name conflicts.

4

Resolve name or classroom conflicts

If two names appear for the same classroom, review both records rather than merging automatically. Choose Merge into existing, Keep separate, or Skip row. Confirm the correct observer and classroom before merging. Use Schedule vs submitted to identify outstanding assignments.

5

Prepare the payment email and save the batch

Open Payment email summary, select the submission date and the classrooms to include, and confirm the observer counts and totals. Click Copy table for email or Export Excel for the accompanying invoice email. Then click Save to Submission History to retain the exact batch. Saving moves included Submitted observations to Processing using the saved submission date.

6

Apply Processing / Completed dates in bulk

In Workflow & bulk dates or a weekly classroom view, select multiple classroom checkboxes, enter one date and click Mark Processing or Mark Completed. Processing requires Submitted; Completed requires Processing. Saving a payment batch may already have set Processing for those classrooms.

7

Follow up and review history

Use Submission log to reopen saved batches and re-export reports. Outstanding submissions are flagged orange at 30–59 days and red at 60+ days from the submission date, until reconciled. Use Change History to review recorded changes and import decisions.

8

Back up at the end of every session

The tracker saves to this browser only. Click ⬇ Backup now in the bar under the header and save the JSON file to the team OneDrive/SharePoint folder. The dot turns amber when no backup has been downloaded in 7 days. To work on another computer, open the site there and ⬆ Restore the newest backup.

Important reminders

Confirm the correct season, CSV type and observer assignments before uploading. Avoid importing the same payment batch twice. Check the email summary amounts against the invoices before sending. Keep staff access restricted. Never upload observation backup files to the GitHub repository; the website holds no data, only the tool. Keep backups on OneDrive/SharePoint. Only one person should edit at a time, and always restore the newest backup before editing on a different computer.

Share this tutorial with authorized staff using the tutorial.html file or the tracker menu More → Quick Start Tutorial. Use Print / Save as PDF to create an attachment for email. Backups include observations, submission history, the Upload Review queue and Change History.
